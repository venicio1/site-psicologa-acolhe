# Site para Psicóloga

Projeto de portfólio de um site para uma psicóloga fictícia. Desenvolvi a página para praticar a criação de uma presença profissional na web, com apresentação dos serviços, navegação entre seções e layout adaptável a diferentes telas.

> **Aviso:** nome, registro profissional, endereço, telefone, formação e demais informações exibidas são fictícios e usados apenas para demonstração.

## Funcionalidades

- Apresentação profissional e descrição das abordagens
- Seções de especialidades, consultório e contato
- Navegação entre as áreas da página
- Atalho demonstrativo para agendamento pelo WhatsApp
- Layout responsivo para celular e computador

## Tecnologias

HTML, CSS e JavaScript. As imagens estão na pasta `images`, e os arquivos de estilo e interação ficam em `css` e `js`.
